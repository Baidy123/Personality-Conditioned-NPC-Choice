# 方程 v1.1 新系数表示例（数值全部为 PROVISIONAL 草稿，仅示意结构）

## 整体结构一图流

```
                    ┌─ 性格 p (OCEAN, 每项 −1..+1)
                    │
  ┌─────────────────┴──────────────────────────────────┐
  │  base：这个候选项本身合不合这个性格的口味？            │
  │                                                    │
  │  强度型特征（8 个）：理想点                           │
  │    理想水平 μ_f = b_f + Σ C[trait,f]·p_trait        │
  │    得分贡献 = −w_f·(候选值 − μ_f)²   ← 偏离越远越差   │
  │                                                    │
  │  关系型特征（action 独有 4 个）：线性                  │
  │    得分贡献 = Σ p_trait·W_rel[trait,f]·候选值        │
  └────────────────────┬───────────────────────────────┘
                       │
  ┌────────────────────┴───────────────────────────────┐
  │  记忆调整：最近去过的 3 个地方（同地点时最近 3 个动作）  │
  │                                                    │
  │    rep = 是不是刚去过的同一个？  → 谁都扣分 (−λ_R·rep) │
  │    fam = 和最近去的像不像？      → 高C加分 / 高O扣分   │
  │                                  (γ = λ_C·C − λ_O·O)│
  └────────────────────┬───────────────────────────────┘
                       │
  ┌────────────────────┴───────────────────────────────┐
  │  温度：N 控制"多严格地按上面的偏好来选"                │
  │    T = exp(λ_N·N)                                   │
  │    N=+1 → T≈2.7 选得飘忽   N=−1 → T≈0.37 选得规律    │
  └────────────────────┬───────────────────────────────┘
                       │
              P = softmax(总分 / T)  → 抽一个选择
```

## 表 1：b^L —— 中性人格的理想水平（location，8 个数）

"性格全为 0 的普通人，觉得每个特征多少最舒服"

| social | stimulation | structure | cognitive | physical | risk | exploration | privacy |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0.50 | 0.50 | 0.50 | 0.40 | 0.40 | **0.20** | 0.40 | 0.40 |

> 读法：普通人喜欢中等热闹（0.5），但天生偏好低风险（0.2）——所以 risk 的基线不是 0.5。

## 表 2：C^L —— trait 对理想水平的推移（location 主表，5×8）

"这个 trait 每 +1，就把这个特征的理想水平推多少"（正 = 往高推，负 = 往低推）

| trait | social | stimulation | structure | cognitive | physical | risk | exploration | privacy |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **O** 开放 | 0 | +0.10 | −0.20 | +0.30 | 0 | +0.20 | **+0.50** | 0 |
| **C** 尽责 | 0 | −0.20 | **+0.40** | +0.10 | +0.10 | −0.30 | −0.10 | +0.10 |
| **E** 外向 | **+0.45** | +0.35 | 0 | 0 | 0 | 0 | 0 | **−0.40** |
| **A** 宜人 | +0.15 | 0 | +0.10 | 0 | 0 | −0.10 | 0 | −0.05 |
| **N** 神经质 | −0.15 | −0.20 | +0.15 | 0 | 0 | **−0.35** | −0.10 | **+0.30** |

> 读法举例（加粗格）：
> - E 行 social 列 = +0.45：外向 +1 的人，理想 social 水平 = 0.50 + 0.45 = 0.95（爱最热闹的地方）；外向 −1 则 = 0.05（爱冷清）。
> - N 行 risk 列 = −0.35：神经质 +1 的人理想 risk = 0.20 − 0.35 → 截到 0（完全回避危险）。
> - 中等外向 E=+0.3：理想 social = 0.50 + 0.45×0.3 ≈ 0.64 → market(0.7) 比 tavern(0.9) 更舒服。这是旧线性表做不到的。

## 表 3：w^L —— 偏离理想的代价（location，8 个数）

## 一个完整的算分小例子

角色：外向开朗（E=+0.8，其余 0）。候选：tavern (social 0.9, stim 0.8, ...) vs library (social 0.2, cognitive 0.8, ...)。

1. 理想水平：μ_social = 0.5 + 0.45×0.8 = **0.86**，μ_privacy = 0.4 − 0.4×0.8 = **0.08**
2. tavern 的 social=0.9，离 0.86 很近 → 几乎不扣分；library 的 social=0.2，差 0.66 → 扣 1.0×0.66² ≈ 0.44
3. 记忆：假设他刚去过 tavern → tavern 的 rep 高，被 −λ_R 压一点 → 不会连刷酒馆
4. 温度：N=0 → T=1，正常按偏好选
5. 结果：大概率去 market 这类"同样热闹但不重样"的地方，偶尔回 tavern，基本不去 library ✔ 符合直觉
