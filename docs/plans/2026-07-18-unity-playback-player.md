# Unity playback player — implementation plan (2026-07-18)

Implements section 5 ("Playback player") of
`docs/specs/2026-07-17-rq3-sequence-interface-design.md` in the Unity project
`unity/dissertation` (2022.3.62f1, 2D built-in pipeline).

Decisions confirmed 2026-07-18 (brainstorm with user):

- On-screen info in recorded clips: location name plates + NPC action label
  only. No step counter. Condition info (policy/personality/seed) is never
  parsed into the player, let alone displayed.
- NPC movement: straight-line constant speed between location blocks.
- Recording method: deferred. Recording mode = auto-advance ON + control bar
  hidden (H key); the frame then contains only scene, name plates, action label.

## Scene (placeholder art)

Fixed orthographic camera (size 5, 16:9 → x∈[−8.9, 8.9], y∈[−5, 5]), all seven
locations visible: quiet side left/top (library, chapel), busy centre (market,
tavern), arena right, forest edge, enemy_camp far corner. Each location = solid
colour block + white name plate. NPC = dark dot with a bob animation while
performing; action id shown above it. All sprites generated by the editor
script (white square / circle PNGs) — swap for a CC0 tileset later.

## Files

- `Assets/Scripts/Playback/SequenceData.cs` — DTOs + `JsonUtility` parse +
  player-side validation (step count vs n_cycles, first `moved` true, `moved`
  consistency). Only neutral meta fields are parsed.
- `Assets/Scripts/Playback/PlaybackModel.cs` — pure step cursor (testable).
- `Assets/Scripts/Playback/LocationLayout.cs` — id → position/colour table +
  NPC start. Layout edits happen here, then rebuild the scene.
- `Assets/Scripts/Playback/NpcAgent.cs` — straight-line move, bob loop,
  action label.
- `Assets/Scripts/Playback/PlaybackController.cs` — dropdown of
  `StreamingAssets/sequences/*.json`, Continue/Restart/Auto UI, hotkeys
  (Space = continue, H = hide UI, R = restart), auto-advance interval
  (inspector, default 4 s).
- `Assets/Scripts/Editor/PlaybackSceneBuilder.cs` — menu
  **Dissertation → Build Playback Scene**: generates sprites, builds camera /
  ground / blocks / plates / NPC / UI, wires the controller, saves
  `Assets/Scenes/Playback.unity`. Rerunnable (layout tweaks = rerun).
- `Assets/Tests/EditMode/SequenceTests.cs` — parse, validation rejections,
  model order, layout covers the seven world.json ids.
- asmdefs: `Dissertation.Playback`, `.Editor`, `.Tests`.
- `Assets/StreamingAssets/sequences/` — smoke sequences copied from
  `data/rq3_sequences/smoke/`.

## Acceptance
