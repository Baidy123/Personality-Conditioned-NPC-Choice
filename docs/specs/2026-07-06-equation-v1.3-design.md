# Equation v1.3 — N familiarity channel + memory-term rebalance

Date: 2026-07-06 · Status: approved (user + supervisor feedback) · Supersedes
the memory term of v1.2 (docs/tuning_log.md round 4); base score, satiation
form, and N temperature are unchanged.

## Trigger

Supervisor review of the RQ1 pilot trajectories:

> "Memory is having quite a dramatic effect, and in nearly all situations, it
> means they are less likely to choose the same thing as they did last time.
> It is making a difference. I don't know if I'd say it works."

Diagnosis confirmed by E3/E4: the satiation penalty (`lambda_R = 1.2`) was a
near-uniform anti-repeat force. Under it, immediate-repeat rates were C+1
0.19, N+1 0.08, O−1 0.02, everyone else ≈ 0 — the memory adjustment carried
almost no personality information. Two structural causes:

1. the trait-carrying familiarity term (`±1.0`) was an order of magnitude
   weaker than the satiation penalty after trajectory-layer sharpening
   (`selection_temperature = 0.1`);
2. N had no designed memory channel at all. Its apparent repeat effects were
   side effects of the temperature: at N=−1 the sharp temperature *amplified*
   satiation (rigid alternation, repeat = 0); at N=+1 the flat temperature
   *diluted* it (random re-picks, repeat = 0.08). Both directions were
   artefacts, not expression.

## Change 1 — N joins the familiarity coefficient

```text
gamma^d = lambda_C^d · C − lambda_O^d · O + lambda_Nf^d · N
```

Interpretation: high N (anxiety) clings to recently familiar options; low N
(emotional stability) leaves them readily. This maps to the **Withdrawal /
Anxiety** facet of Neuroticism, coexisting with the temperature channel which
maps to **Volatility** (cf. DeYoung's two-aspect decomposition). The two
channels partially cancel in magnitude — the temperature divides the
familiarity bonus by `e^{lambda_N}` ≈ 4.5 at N=+1 — so `lambda_Nf` must
outsize `lambda_O`/`lambda_C` to land a comparable effect. This dilution is an
intended property (an anxious NPC is erratic in base preference yet sticky to
the recent and safe), documented rather than removed.

Rejected alternative (measured): moving the memory terms outside the
temperature division, `P = softmax(base/(tau_0·T_N) + gamma·fam − rho·rep)`.
This restores full-strength satiation at N=+1 and *reverses* the intended
effect (N+1 repeat → 0.00, N−1 → 0.11).

## Change 2 — coefficient rebalance (grid-searched, tied across levels)

| knob | v1.2 → v1.3 | role |
|---|---|---|
| `lambda_R` | 1.2 → 0.7 | lower the uniform anti-repeat floor so trait channels have room in both directions |
| `kappa_C` | 0.5 → 0.8 | high C now nearly immune to satiation (routine tolerance) |
| `lambda_O` / `lambda_C` | 1.0 → 2.0 | strengthen the trait-carrying familiarity term |
| `lambda_Nf` | — → 3.0 | new N channel (see dilution note above) |

Grid: `lambda_R ∈ {0.7, 0.9, 1.1} × kappa_C ∈ {0.7, 0.8, 0.9} ×
lambda_OC ∈ {1.5, 2.0} × lambda_Nf ∈ {2, 3}`, objective = the weakest of the
three trait separations `d_C = rep(C+1) − rep(C−1)`, `d_O = rep(O−1) −
rep(O+1)`, `d_N = rep(N+1) − rep(N−1)` on 50-round × 5-seed trajectories,
subject to no neutral-profile degeneracy. The chosen cell maximises all three;
`kappa_C = 1.0` was excluded earlier (C+1 locks to 2 locations at repeat 0.83+,
judged too extreme).

## Effects (50 rounds × 10 seeds, `selection_temperature = 0.1`)

Immediate location-repeat rate, memory-free → full memory (E4):

| profile | v1.2 full | v1.3 full | v1.3 delta vs memory-free |
|---|---|---|---|
| C+1 | 0.19 | **0.73** | **+0.13** (memory attracts) |
| N+1 | 0.08 | **0.36** | **+0.08** (memory attracts) |
| O−1 | 0.02 | **0.22** | −0.15 (mild) |
| C−1 / O+1 | 0.00 | 0.00 | −0.54 / −0.52 (memory repels) |
| E±1, A±1 | ≈0 | 0.02–0.10 | −0.28 to −0.73 (base-driven, as designed) |
| neutral | 0.01 | 0.05 | −0.64 (guard intact: 5.9 distinct locations) |

The memory adjustment now has personality-dependent *sign*, not just
magnitude: it pulls routine-loving (C+1), anxious (N+1), and conventional
(O−1) profiles back to recent choices and pushes novelty-seeking (O+1) and
easily-bored (C−1) profiles away, answering the supervisor's objection
directly.

Named profiles: Shadowheart (N 0.6, C 0.4) now cycles chapel↔library
(2 distinct, repeat 0.39) — judged in character by the user ("在她故事线结束
之前感觉她就是这种性格"); all other named profiles keep ≥ 4 distinct
locations. E1 N expression strengthened (context-avg TVD 0.48, action 0.53);
E2 Spearman ρ 0.430 (was 0.451), Mantel p = 0.001 — no meaningful loss.
