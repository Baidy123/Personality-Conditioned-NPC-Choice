# Design: Hand-Authored Scorer Equation v1.1

Date: 2026-07-02 · Status: approved by user (conversation), pending spec review
Scope: `code/npc_policy` hand-authored scorer only. Learned models, weight tuning, and experiment design are out of scope (phase 2/3).

## 1. Summary

Replace the v1 scorer equation with v1.1:

1. **Base score** switches to an **ideal-point form** (default), with the existing bilinear form retained behind a config switch as a debugging fallback.
2. **Memory adjustment** becomes `γ(p)·fam − λ_R·rep` with `γ(p) = λ_C·C − λ_O·O`; the `λ_E·E·compat_E·sim` term is deleted.
3. **Temperature** becomes bidirectional: `T_N = exp(λ_N·N)`.
4. The `log(P_base + ε)` two-stage computation is removed (mathematically equivalent simplification); `epsilon` is deleted from config.

Rationale and equivalence arguments are recorded in the conversation and in
`docs/equation_v1.1_tables_example.md` (worked example), `docs/v11_tables.png`,
`docs/v11_ideal_levels_demo.png` (table illustrations with draft values).

## 2. Final equation

For decision level `d ∈ {L, A}` over candidates `o_1..o_m` in the native schema:

```text
# --- base (base_form = "ideal_point", default) ---
Intensity features f (location: all 8; action: the shared 7, no privacy):
    mu_f(p)   = clip(b_f^d + Σ_t C^d[t, f] · p_t, 0, 1)
    intensity = − Σ_f w_f^d · (o_i[f] − mu_f(p))²

Relational features f (action only: cooperation, helping, conflict, control):
    relational = Σ_t Σ_f p_t · W_rel^A[t, f] · o_i[f]

base_i = intensity + relational          # locations have no relational part

# --- base (base_form = "bilinear", fallback) ---
base_i = p^T W^d o_i^d                   # existing v1 form, unchanged

# --- memory + temperature (shared by both base forms) ---
fam_i  = sim_i                           # recency-weighted cosine, computed as today
q_i    = base_i / tau_0
         + (lambda_C · C − lambda_O · O) · fam_i
         − lambda_R · rep_i
T_N    = exp(lambda_N · N)
P_rule = softmax(q / T_N)
```

Behavioural reading:

- Traits shift each intensity feature's **preferred level**; deviation in either
  direction costs score. Mid-range personalities can prefer mid-range feature
  levels, which the bilinear form cannot express.
- Every trait participates in base scoring (each has a row in `C` and `W_rel`).
  Additionally: O and C modulate the memory adjustment (novelty seeking vs
  routine), N controls choice temperature (erratic vs predictable). E and A act
  through base only.
- `rep` remains a personality-independent repetition penalty (universal satiation).
- Empty buffer ⇒ `rep = fam = 0` ⇒ `P_rule = softmax(base/tau_0 / T_N)` (unchanged rule).
- `nov = 1 − sim` is no longer used by the scorer but stays in `relations.py` /
  `cases.py` as a learned-model input feature.
- `tau_0` is kept as the single global sharpness knob for phase-2 tuning.

## 3. New hand-authored tables (all values PROVISIONAL)

| Table | Shape | Meaning |
|---|---|---|
| `b^L`, `b^A` | (8,), (7,) | baseline ideal level per intensity feature (neutral personality) |
| `C^L`, `C^A` | (5, 8), (5, 7) | trait → ideal-level shift |
| `w^L`, `w^A` | (8,), (7,) | deviation cost per intensity feature |
| `W_rel^A` | (5, 4) | linear weights for the 4 relational action features (seeded from the last 4 columns of the current `W^A`) |
| `W^L`, `W^A` (existing) | unchanged | used only by the bilinear fallback |

Draft starting values: see `docs/v11_tables.png` (location level; action level is
authored analogously without the privacy column). All new tables live in
`weights.py` with the same dict-literal style as the current `_W_L` / `_W_A`.

(mirroring the existing `W_location`/`W_action` arguments).

## 5. Verification

`pytest` suite (new `code/tests/`):

1. **Bilinear regression**: with `base_form="bilinear"`, an empty buffer, and
   `N = 0` (so `T_N = 1`), `P_rule` equals v1's `P_base = softmax(p^T W o / tau_0)`.
2. **Order equivariance**: permuting candidates permutes probabilities, values unchanged.
3. **Empty buffer**: `P_rule == softmax(base/tau_0 / T_N)`; no memory adjustment.
4. **Bidirectional N**: entropy(P | N=−1) < entropy(P | N=0) < entropy(P | N=+1), other traits fixed.
5. **Ideal-point signature**: a mid-E personality assigns highest probability to the
   mid-social candidate among social ∈ {0.2, 0.65, 0.9} (other features equal).
6. **γ direction**: after visiting a location, a similar candidate's probability rises
   for high-C (relative to C=0) and falls for high-O.

Manual sanity script (`examples/trait_sweep.py`): sweep each trait −1→+1 with the
other traits at 0 on a fixed candidate set; print the choice distributions for
eyeball checks. This is the entry point for phase-2 debugging.
