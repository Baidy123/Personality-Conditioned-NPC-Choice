## 整体结构一图流

```
                    ┌─ 性格 p (OCEAN, 每项 −1..+1)
                    │
  ┌─────────────────┴──────────────────────────────────┐
  │  base：这个候选项本身合不合这个性格的口味？            │
  │                                                    │
  │  强度型特征（location 9 个 / action 7 个）：理想点     │
  │    理想水平 μ_f = clip(b_f + Σ C[trait,f]·p_trait, 0, 1)
  │    得分贡献 = −w_f·(候选值 − μ_f)²   ← 偏离越远越差   │
  │                                                    │
  │  关系型特征（action 独有 4 个）：线性                  │
  │    得分贡献 = Σ p_trait·W_rel[trait,f]·候选值        │
  └────────────────────┬───────────────────────────────┘
                       │
  ┌────────────────────┴───────────────────────────────┐
  │  记忆调整：最近去过的 3 个地方（同地点时最近 3 个动作）  │
  │                                                    │
  │    rep = 是不是刚选过的同一个？ → 扣分 −ρ·rep         │
  │          ρ = λ_R·(1 − κ_C·C)  ← v1.2：高C耐重复、    │
  │                                  低C容易腻           │
  │    fam = 和最近选的像不像？ → 高C加分 / 高O扣分 /      │
  │          高N加分（焦虑粘熟悉，v1.3）                   │
  │          (γ = λ_C·C − λ_O·O + λ_Nf·N)               │
  └────────────────────┬───────────────────────────────┘
                       │
  ┌────────────────────┴───────────────────────────────┐
  │  温度：N 控制"多严格地按上面的偏好来选"                │
  │    T = exp(λ_N·N)，当前 λ_N = 1.5                    │
  │    N=+1 → T≈4.5 选得飘忽   N=−1 → T≈0.22 选得规律    │
  └────────────────────┬───────────────────────────────┘
                       │
              P = softmax(总分 / T)  → 抽一个选择
```

当前标量（`config.py`，均 PROVISIONAL，round 7 / v1.3 起）：λ_R=0.7，κ_C=0.8，
λ_O=λ_C=2.0，λ_Nf=3.0（γ 里的 N 项在温度内被 e^1.5≈4.5 稀释，故系数偏大），
λ_N=1.5；τ_0 location 层 0.9（round 5 起与 action 层的 1.0 分离）、action 层 1.0。

## 表 1：b^L —— 中性人格的理想水平（location，9 个数）

"性格全为 0 的普通人，觉得每个特征多少最舒服"

| social | stimulation | structure | cognitive | physical | risk | exploration | privacy | conflict |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| 0.475 | 0.50 | 0.50 | 0.40 | 0.40 | **0.20** | 0.40 | 0.40 | **0.10** |

> 读法：普通人喜欢中等热闹（0.475），但天生偏好低风险（0.2）、几乎不想待在有打斗的地方（0.1）。

## 表 2：C^L —— trait 对理想水平的推移（location 主表，5×9）

"这个 trait 每 +1，就把这个特征的理想水平推多少"（正 = 往高推，负 = 往低推）

| trait | social | stimulation | structure | cognitive | physical | risk | exploration | privacy | conflict |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **O** 开放 | 0 | +0.10 | −0.20 | **+0.45** | 0 | +0.20 | **+0.55** | 0 | 0 |
| **C** 尽责 | 0 | −0.20 | **+0.40** | +0.10 | +0.10 | −0.30 | −0.10 | +0.10 | 0 |
| **E** 外向 | **+0.45** | +0.35 | 0 | 0 | 0 | 0 | 0 | **−0.40** | 0 |
| **A** 宜人 | +0.15 | 0 | +0.10 | 0 | 0 | −0.10 | 0 | −0.05 | **−0.35** |
| **N** 神经质 | −0.15 | −0.20 | +0.15 | 0 | 0 | **−0.35** | −0.10 | **+0.30** | −0.20 |

> 读法举例（加粗格）：
> - E 行 social 列 = +0.45：外向 +1 的人，理想 social 水平 = 0.475 + 0.45 ≈ 0.93（爱最热闹的地方）；外向 −1 则 ≈ 0.03（爱冷清）。
> - N 行 risk 列 = −0.35：神经质 +1 的人理想 risk = 0.20 − 0.35 → 截到 0（完全回避危险）。
> - **conflict 列（v1.2 新增）**：μ_conflict = 0.10 − 0.35·A − 0.20·N。凶悍（A=−0.9）且无畏（N=−0.7）的战士理想值 ≈ 0.56 → 主动寻找武斗场所；温和或焦虑的人停在 0.1 附近 → 回避。这一列让"爱去竞技场"在地点层可表达（round 4 前做不到）。
> - 中等外向 E=+0.3：理想 social = 0.475 + 0.45×0.3 ≈ 0.61 → market(0.7) 比 tavern(0.9) 更舒服。这是旧线性表做不到的。

## 一个完整的算分小例子

角色：外向开朗（E=+0.8，其余 0）。候选：tavern (social 0.9, stim 0.8, ...) vs library (social 0.2, cognitive 0.8, ...)。

1. 理想水平：μ_social = 0.475 + 0.45×0.8 = **0.835**，μ_privacy = 0.4 − 0.4×0.8 = **0.08**
2. tavern 的 social=0.9，离 0.835 很近 → 几乎不扣分；library 的 social=0.2，差 0.635 → 扣 0.8×0.635² ≈ 0.32
3. 记忆：假设他刚去过 tavern → tavern 的 rep 高，被 −ρ 压一点（E 不影响 ρ，中性 C 时 ρ=λ_R=0.7）→ 不会连刷酒馆
4. 温度：N=0 → T=1，正常按偏好选
5. 结果：大概率去 market 这类"同样热闹但不重样"的地方，偶尔回 tavern，基本不去 library ✔ 符合直觉
